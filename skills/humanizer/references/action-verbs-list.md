# Action Verbs List

A curated directory of 100+ high-impact technical action verbs categorized by engineering domain. Use these verbs at the start of every resume bullet point to replace weak or passive language.

---

## 1. Building & Software Development

Use when creating new applications, modules, APIs, or user interfaces:

- **Architected** — *Architected a microservices backend using FastAPI and Docker...*
- **Built** — *Built a responsive web dashboard in React and Tailwind...*
- **Constructed** — *Constructed custom REST endpoints for authenticating user sessions...*
- **Created** — *Created an automated email processing script in Python...*
- **Deployed** — *Deployed serverless functions on AWS Lambda handling image processing...*
- **Developed** — *Developed a full-stack e-commerce web application...*
- **Engineered** — *Engineered a low-latency data ingestion pipeline...*
- **Implemented** — *Implemented OAuth2 authentication for secure user logins...*
- **Programmed** — *Programmed asynchronous network sockets in C++...*
- **Prototyped** — *Prototyped an IoT sensor monitoring tool using Node.js...*
- **Structured** — *Structured relational database schemas in PostgreSQL...*

---

## 2. Optimizing & Refactoring

Use when improving speed, efficiency, memory usage, or code quality:

- **Accelerated** — *Accelerated page load times by 40% through code splitting...*
- **Automated** — *Automated repetitive regression testing routines using PyTest...*
- **Boosted** — *Boosted test coverage from 65% to 92%...*
- **Condensed** — *Condensed database query complexity, cutting execution times...*
- **Enhanced** — *Enhanced API security by enforcing strict rate limiting...*
- **Maximized** — *Maximized server resource utilization by migrating to Docker...*
- **Minimized** — *Minimized memory overhead by 25% through algorithm refactoring...*
- **Optimized** — *Optimized SQL queries to reduce indexing overhead...*
- **Refactored** — *Refactored legacy codebase into modular TypeScript components...*
- **Resolved** — *Resolved memory leak issues across background worker threads...*
- **Restructured** — *Restructured data models to support horizontal scaling...*
- **Streamlined** — *Streamlined CI/CD deployment pipelines, cutting build time in half...*

## 3. Artificial Intelligence & Data Science

Use when training models, building RAG pipelines, or handling data:

- **Analyzed** — *Analyzed large-scale sensor telemetry datasets using Pandas...*
- **Benchmarked** — *Benchmarked multiple LLM configurations for inference latency...*
- **Cleaned** — *Cleaned and preprocessed unstructured text datasets...*
- **Clustered** — *Clustered customer behavioral metrics using K-Means...*
- **Extracted** — *Extracted key entity features from unformatted PDF documents...*
- **Fine-tuned** — *Fine-tuned open-source LLMs using LoRA techniques...*
- **Generated** — *Generated synthetic training data to balance edge-case classes...*
- **Mined** — *Mined user interaction logs to discover usage patterns...*
- **Modelled** — *Modelled predictive time-series forecasts using Prophet...*
- **Quantized** — *Quantized PyTorch neural network weights for edge deployment...*
- **Scraped** — *Scraped 50K+ public datasets using Scrapy and Selenium...*
- **Trained** — *Trained vision models achieving 94% classification precision...*

## 4. Infrastructure, DevOps & Cloud

Use when managing cloud resources, deployments, and CI/CD pipelines:

- **Configured** — *Configured NGINX reverse proxy servers for load balancing...*
- **Containerized** — *Containerized legacy applications using Docker & Kubernetes...*
- **Integrated** — *Integrated Prometheus and Grafana for system monitoring...*
- **Migrated** — *Migrated on-premise workloads to AWS S3 and EC2...*
- **Orchestrated** — *Orchestrated multi-node Kubernetes clusters for high availability...*
- **Provisioned** — *Provisioned infrastructure-as-code using Terraform scripts...*
- **Secured** — *Secured internal microservices using SSL/TLS encryption...*

---

## 5. Banned Weak Phrases (Do NOT Use)

| Avoid Weak Phrase | Replace With Strong Action Verb |
|---|---|
| *Worked on...* | **Engineered**, **Developed**, **Constructed** |
| *Responsible for...* | **Managed**, **Directed**, **Executed** |
| *Helped with...* | **Collaborated**, **Assisted**, **Supported** |
| *Handled...* | **Resolved**, **Processed**, **Administered** |
| *Was involved in...* | **Contributed to**, **Co-authored**, **Implemented** |
