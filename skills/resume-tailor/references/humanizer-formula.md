# Humanizer Bullet Rewriting Formula

Every tailored bullet point written into LaTeX must follow the high-impact copywriter framework:

$$\text{[Strong Action Verb]} + \text{[Core Task / System Built]} + \text{[Tools / Technologies]} + \text{[Measurable Impact / Metric]}$$

---

## 🚫 Banned AI Buzzwords & Passive Phrases

Never begin bullets with weak or robotic expressions:
- ❌ *"Responsible for..."*
- ❌ *"Worked on..."*
- ❌ *"Helped with..."*
- ❌ *"Spearheaded synergies..."*
- ❌ *"Leveraged cutting-edge solutions..."*
- ❌ *"Utilized technologies to facilitate..."*

---

## ⚡ High-Impact Power Verbs (By Domain)

- **AI, ML & Data:** Engineered, Fine-tuned, Benchmarked, Scaled, Deployed, Trained, Architected, Optimized, Indexed.
- **Software Engineering:** Developed, Refactored, Accelerated, Containerized, Integrated, Automated, Resolved.
- **Leadership & Product:** Spearheaded, Delivered, Mentored, Established, Standardized, Orchestrated.

---

## 💡 Real Bullet Transformations

| Raw Input | Tailored Humanized Bullet |
| :--- | :--- |
| *"Fixed bugs in Python database script"* | *"Resolved critical database bottlenecks in Python & PostgreSQL, improving query execution speed by 35%."* |
| *"Worked on LLMs and RAG system for company"* | *"Engineered enterprise RAG pipeline with Qdrant & LangChain, cutting hallucinations by 40% across 50K queries."* |
| *"Did CI/CD pipeline using Docker"* | *"Automated CI/CD deployment workflows with Docker & GitHub Actions, reducing release cycle time from 2 hours to 15 mins."* |

---

## Strict Rule on Truthfulness
- **Source of Truth:** Extract tools and projects strictly from `about_me.md`.
- **Never Fabricate Metrics:** If an exact percentage is not in `about_me.md`, use precise technical outcomes (e.g. *"achieving zero-downtime deployment"* or *"handling 10K+ concurrent requests"*) based on real work described in `about_me.md`.
